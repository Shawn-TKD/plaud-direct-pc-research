# 固件研究对 Recorder Hub 的改进建议

## 当前 Wi-Fi 快传状态

0.6.0 已经实现官方 SDK 管理的 Wi-Fi 快传，不是占位界面：

- `SyncManager.startWifiTransfer()` 调用 `PlaudDeviceAgent.startWifiTransfer()`。
- 握手进入 `READY` 后主动获取 Wi-Fi 文件列表。
- 文件按顺序交给 `exportAudioViaWiFi()`，由 SDK 完成加密音频解密和 MP3 导出。
- 界面显示连接阶段、总进度、单文件进度和速度。
- Android 13 及以上申请 `NEARBY_WIFI_DEVICES`，旧版本使用定位权限。
- 结束时等待设备关闭 Wi-Fi，并恢复 BLE 自动重连。
- `AUTO_DELETE_AFTER_SYNC=false`，同步后保留设备原文件。

因此，手机端现在可以使用 Wi-Fi 快传。电脑端 `plaud-pc-bridge` 当前只实现 BLE 下载，尚未复现命令 120–126 对应的 Wi-Fi 配网和传输协议。

## 优先改进

1. **显示逐文件失败结果。** 当前 Wi-Fi 导出回调遇到单个文件失败后继续处理队列，最终可能仍显示整体完成。应保留失败的 session ID 和原因，并在结尾显示“部分完成”，提供只重试失败项。
2. **补充完整性和断点信息。** 把 SDK 提供的长度、校验和恢复偏移展示在诊断日志中；临时文件完成校验后再进入媒体库。
3. **增加设备日志诊断。** 固件命令 142–146 提供设备日志通道。若 SDK 暴露对应接口，可在失败页生成经过脱敏的诊断包，避免用户手工抓 Logcat。
4. **按需连接。** NotePin 休眠时依赖广播唤醒和短时 GATT 会话，在需要同步时连接，完成后释放；这比持续占用 BLE 更符合固件电源模型。
5. **丰富设备状态。** 将固件命令 3、6、9、141 对应的录音状态、场景、隐私模式、U 盘状态和认证材料存在状态映射到诊断页。
6. **研究闲置 Wi-Fi 自动同步。** 命令 120–126 表明固件支持保存 Wi-Fi、测试网络并在闲置时启动传输。先在隔离测试页验证，再决定是否替代当前手动热点流程。
7. **补齐录音控制。** 固件中的暂停、恢复、标签和标记命令可完善远程录音交互；只有 SDK 提供稳定公开入口时才接入正式界面。

## 不进入普通界面的能力

解绑、恢复出厂、OTA、Find My 令牌修改和认证重置会改变设备状态。它们只适合独立的维护工具，并需要明确的用户操作，不应与日常同步共用入口。
